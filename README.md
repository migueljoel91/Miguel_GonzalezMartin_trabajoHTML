## 📝 Descripción y Estructura del Proyecto

"Vulkania Heavy" es una plataforma web orientada al sector del equipamiento deportivo y entrenamiento de alta gama en Canarias. El sitio ha sido construido desde cero aplicando los estándares actuales de maquetación y diseño web adaptativo.

### 📁 Estructura de navegación y carpetas del repositorio:

1. **Página Principal:**
   - `index.html`: Punto de entrada con presentación de la marca y catálogo destacado.

2. **Secciones / Vistas (`/VIEWS/`):**
   - `/VIEWS/productos.html`: Catálogo completo de productos estructurado en secciones (Racks y estaciones, Mancuernas y peso libre, Bancos de entrenamiento).
   - `/VIEWS/presupuesto.html`: Formulario de solicitud de presupuesto con validaciones en HTML5 (patrones regex para teléfono, campos obligatorios) y adjunción de archivos.
   - `/VIEWS/contacto.html`: Información de contacto, canales directos y mapa de ubicación interactivo enlazado a Google Maps.

3. **Hojas de Estilo (`/CSS/`):**
   - `/CSS/styles.css`: Estilos globales, paleta de colores, cabecera y pie de página.
   - `/CSS/presupuesto.css`: Estilos específicos para la maquetación del formulario.
   - `/CSS/contacto.css`: Estilos específicos para la distribución de la vista de contacto.

4. **Recursos Multimedia y Favicon (`/ASSETS/`):**
   - `/ASSETS/Images/`: Imágenes optimizadas del catálogo y ubicación.
   - `/ASSETS/Favicon/`: Configuración completa de favicons y manifiesto web.

## 🛠️ Tecnologías y Buenas Prácticas Aplicadas

- **HTML5 Semántico:** Uso estructurado de etiquetas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<fieldset>`, `<footer>`) garantizando máxima accesibilidad.
- **CSS3 Avanzado:** Paleta de colores coherente, diseño mediante Flexbox/Grid y maquetación adaptativa (*Responsive Design*) para móviles y escritorio.
- **Optimización SEO y Metadatos:** Configuración personalizada de metaetiquetas (`description`, `author`, `locality`, `keywords`, `robots`) en cada una de las páginas.
- **Validación de Formularios:** Uso de tipos de input específicos (`email`, `tel` con regex) y atributos de obligatoriedad (`required`).
- **Control de Versiones y Despliegue:** Control de cambios con Git y publicación en servidor en vivo mediante GitHub Pages.
